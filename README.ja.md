# ComfyUI Pose Gallery · オンラインポーズギャラリー

[English](README.md) · [简体中文](README.zh-CN.md) · **日本語**

ComfyUI 内でオンラインの素体ポーズ参考画像を探し、ポーズとアングルを選んで、元画像を `IMAGE` としてワークフローに渡すカスタムノードです。

既存の [Anhao 中国語ギャラリー](https://ai-pose-gallery.anhao.app/) と[日本語のオリジナルサイト](https://ai-pose-gallery.pages.dev/)を利用し、必要な画像だけを取得します。インストール時に画像集全体や追加モデルをダウンロードする必要はありません。

## インストール

ComfyUI の `custom_nodes` ディレクトリで実行します。

```bash
git clone https://github.com/icefox57/ComfyUI-Pose-Gallery.git
```

`ComfyUI/custom_nodes/ComfyUI-Pose-Gallery/__init__.py` があることを確認し、ComfyUI を再起動してからブラウザーを強制再読み込みします（Windows：`Ctrl+F5`）。

標準的な ComfyUI 環境には必要な Python 依存関係が含まれています。PyTorch の追加インストールや `npm install` は不要です。Windows ポータブル版では `ComfyUI_windows_portable/ComfyUI/custom_nodes/` に配置し、Python コマンドには付属の `python_embeded/python.exe` を使用してください。

Git でインストールした場合は、プラグインのディレクトリで `git pull` を実行して更新し、ComfyUI の再起動とブラウザーの再読み込みを行います。

## 画像を選ぶ

1. ノードメニューで **Pose Gallery** を検索して追加します。
2. `language` で表示言語を選びます。`zh` は中文、`en` は English、`ja` は日本語です。既存のワークフローでは中国語が初期値になります。
3. **ポーズを選択** をクリックします。キーワード、系統、分類、アングルで絞り込み、カードをクリックすると元画像を確認できます。同じポーズの別アングルも選べます。
4. **この画像を使用** をクリックし、ノードの `image` 出力を接続してワークフローを実行します。

一覧には一度に 24 組のポーズを表示します。さらに読み込むボタンや、更新・絞り込み解除の操作も利用できます。`Esc` でギャラリーを閉じ、`Tab` と `Enter` で各コントロールを操作できます。

選択した画像 ID、取得元のモード、表示言語はワークフローに保存されます。`full_sexy_P001_front` のように ID を直接入力することも可能です。各 ID は、特定のアングルの画像 1 枚を指します。

## 表示言語と取得元

ノードとギャラリーの表示言語は、中国語・英語・日本語に切り替えられます。操作部と一般的な絞り込みラベルはローカルで翻訳されます。ポーズ名は取得元カタログの原文を使用します。独立した英語の画像配信元はありません。

| 表示言語 | キャッシュがない場合の `auto` の取得順 |
| --- | --- |
| 中文（`zh`、初期値） | 中国語サイト → 日本語サイト |
| English（`en`） | 中国語サイト → 日本語サイト |
| 日本語（`ja`） | 日本語サイト → 中国語サイト |

表示言語を変更すると `source` は `auto` に戻ります。その後、`zh` または `ja` を選ぶと、指定したサイトだけを使用します。手動指定中は自動で切り替わりません。言語を変更するか、再び `auto` を選ぶと自動切り替えに戻ります。

自動切り替えはカタログと個別の画像の両方に適用されます。代替サイトにも**同じ画像 ID**を要求するため、取得できない画像が別のポーズに置き換わることはありません。

## 入力と出力

| 入力 | 説明 |
| --- | --- |
| `pose_id` | 選択した画像 ID。ギャラリーで設定するか、直接入力します |
| `source` | 自動（`auto`）、中国語サイトのみ（`zh`）、日本語サイトのみ（`ja`） |
| `language` | 中国語（`zh`）、英語（`en`）、日本語（`ja`）。初期値は `zh` |

| 出力 | 型 | 説明 |
| --- | --- | --- |
| `image` | `IMAGE` | 元のポーズ参考画像 |
| `pose_name` | `STRING` | ポーズ名とアングル。カタログが未保存の場合は画像 ID |
| `source_url` | `STRING` | 出力画像のオンライン取得元 URL |

接続例：

```text
Pose Gallery → Preview Image
Pose Gallery → DWPose / OpenPose 前処理ノード → 対応する ControlNet ワークフロー
Pose Gallery → 画像参照ワークフロー
```

**ギャラリーの画像は素体の参考画像であり、OpenPose の骨格マップではありません。** OpenPose ControlNet には、適切な前処理でポーズを抽出し、ベースモデルに対応する ControlNet モデルを使用してください。前処理ノードとモデルは、お使いの ComfyUI 環境で用意します。

## サンプルワークフロー

- [画像の選択とプレビュー](examples/pose_gallery_preview.json)：JSON を ComfyUI にドラッグして実行できます。ギャラリーで画像を選び直すこともできます。
- [API リクエスト](examples/pose_gallery_api.json)：`PoseGallery → PreviewImage` の API prompt です。

リポジトリのディレクトリから実行します。

```bash
curl -X POST http://127.0.0.1:8188/prompt -H "Content-Type: application/json" --data-binary @examples/pose_gallery_api.json
```

ComfyUI のアドレスやポートが異なる場合は、URL を変更してください。

## ネットワークとキャッシュ

オンラインの取得処理は ComfyUI バックエンドが行います。ブラウザーでサイトを開ける場合でも、**ComfyUI を実行している PC またはサーバー**から配信元に接続できる必要があります。

サムネイルは必要に応じて読み込み、元画像はプレビュー・選択・実行時に取得します。各サイトではそのサイトの保存済み画像を先に確認します。予備サイトの画像が保存されていても、優先サイトを先に確認する順序は変わりません。カタログのキャッシュは 1 時間有効で、配信元が利用できない場合は直近のキャッシュを表示できます。画像集全体をオフラインで提供する機能ではありません。

キャッシュの既定の保存先は、ComfyUI ユーザーディレクトリ内の `pose_gallery/cache` です。環境変数 `POSE_GALLERY_CACHE_DIR` で変更できます。ユーザーディレクトリ API がない旧バージョンでは、システムの一時ディレクトリ内の `comfyui_pose_gallery/cache` を使用します。

読み込みに失敗したら、更新、別の取得元への切り替え、バックエンドのネットワーク・プロキシ設定を確認してください。プラグインはシステムのネットワーク設定を変更しません。ノードやギャラリーボタンが表示されない場合は、ZIP 展開後の余分な階層がないか確認し、ComfyUI の再起動、ブラウザーの強制再読み込み、コンソールのインポートエラー確認を行ってください。

## ポーズ素材の提供を歓迎します

**高品質な素体ポーズ参考素材の提供は、どなたでも歓迎します。** [GitHub Issues](https://github.com/icefox57/ComfyUI-Pose-Gallery/issues) で素材を紹介するか、取得元の追加をプルリクエストで提案してください。次の情報があると確認しやすくなります。

- 少数のサンプルへのリンク、ポーズ内容、解像度、利用できるアングル。
- 作者名と元の公開先 URL。
- 利用・再配布のライセンス、または作者による画像のホスティング・配布許可。
- 安定した ID、ポーズ名、分類、アングルなどのメタデータ。

ご自身の作品や、必要な許可を得た素材をお待ちしています。輪郭が明確で、構図が統一され、十分な解像度と同一ポーズの複数アングルがある画像は特に役立ちます。再配布が禁止されている既存ギャラリーの画像をアップロードしないでください。オンラインの配信元を提案する場合は、画像集全体をコピーせず、リンクを共有してください。

## 開発と検証

Python ノードとビルド不要の JavaScript を使用しています。通常の ComfyUI 依存関係がある Python 環境と、新しい Node.js で確認できます。

```bash
python -m unittest discover -s tests -v
node --test tests/frontend.test.mjs
node --check web/pose_gallery.js
```

過去の実機検証とその範囲は [docs/VALIDATION.md](docs/VALIDATION.md) を参照してください。これらの記録は、各バージョンのブラウザー表示や手動操作の確認を保証するものではありません。データ形式は[連携メモ](docs/UPSTREAM.md)、変更点は[変更履歴](CHANGELOG.md)に記載しています。
