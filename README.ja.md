# ComfyUI Pose Gallery · ローカルポーズギャラリー

[English](README.md) · [简体中文](README.zh-CN.md) · **日本語**

ComfyUI 内でポーズ参考画像を選び、画像とポーズプロンプトをワークフローに接続できます。中国語版を基にしたローカルファイルを使用するため、インストール後の閲覧と実行にネット接続は不要です。

## インストール

ComfyUI の `custom_nodes` ディレクトリで次のコマンドを実行し、ComfyUI を再起動してブラウザーを強制更新してください（Windows は `Ctrl+F5`）。

```bash
git clone https://github.com/icefox57/ComfyUI-Pose-Gallery.git
```

リポジトリには上流の画像とカタログは含まれません。ComfyUI の Python を使い、次のコマンドで中国語サイトから原寸画像 1,439 枚（約 638 MiB）を一度準備してください。

```bash
python scripts/setup_assets.py --download
```

中国語版のファイルをすでに持っている場合は、`python scripts/setup_assets.py --from-directory ギャラリーディレクトリ` でオフラインに取り込めます。元ディレクトリには `img/` と `data/pose-zh.json` が必要です。`data/pose.json` があれば日本語名も取り込みます。中断した場合は再実行できます。素材は `assets/zh/` に保存され、異なる既存画像は上書きしません。ダウンロード前に回線と通信量をご確認ください。

通常の ComfyUI に必要な Python 依存関係は含まれ、追加モデルや npm のインストールは不要です。ポータブル版では ComfyUI ディレクトリ内の `custom_nodes` と付属の Python を使用してください。

更新するにはプラグインのディレクトリで `git pull` を実行し、ComfyUI を再起動してブラウザーを更新してください。

## 使い方

1. ノードメニューから **Pose Gallery** を追加します。
2. `language` を `zh`、`en`、`ja` に設定し、ポーズ選択ボタンをクリックします。
3. 検索またはカテゴリ・角度で絞り込み、カードをクリックしてプレビューと視点を選び、画像を使用するボタンを押します。
4. `image` を参照画像ワークフローに接続します。`sd_prompt` を使う場合は **CLIP Text Encode (Prompt)** の text ウィジェットを入力に変換して接続します。

一度に 24 グループを表示し、ボタンで追加表示できます。`Esc` で閉じます。画像 ID と言語はワークフローに保存されます。`full_sexy_P001_front` のように ID を直接入力することもできます。

| 出力 | 型 | 内容 |
| --- | --- | --- |
| `image` | `IMAGE` | ローカルの原寸参考画像 |
| `pose_name` | `STRING` | 中国語または日本語のポーズ名と角度。英語 UI では中国語名 |
| `source_url` | `STRING` | ローカル画像の `file:` URI（v0.4.0 からオンライン URL ではありません） |
| `sd_prompt` | `STRING` | 人物と動作を表す英語の SD タグ |

288 のポーズグループには整理済みのタグがあり、同じポーズの各視点で共有します。未整理の新しいポーズは空文字列を返します。画像は参考画像であり、OpenPose の骨格図ではありません。骨格を使う場合は対応するポーズ前処理器と ControlNet を使用してください。[サンプルワークフロー](examples/)もあります。

UI とフィルターは中国語・英語・日本語に対応します。日本語名はローカルの日本語ラベルから読み込み、言語を変更しても画像ソースは変わりません。旧ワークフローの出力順は維持され、旧 `source` 値は受け付けますが読み込みには影響しません。
